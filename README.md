# Analog CMOS Design Portfolio

This repository contains my Analog CMOS Design analysis and simulation work.

The work focuses on understanding transistor-level concepts through:

- Hand analysis and calculations
- Cadence Virtuoso and LTspice simulations
- Comparison between theoretical concepts and practical circuit behaviour

The concepts are studied from:

*Design of Analog CMOS Integrated Circuits* — Behzad Razavi


## Chapter 2 — Basic MOS Device Physics

Documentation covering:

- MOSFET operating regions
- NMOS and PMOS characteristics
- Small-signal parameters
- Body effect
- Second-order effects

Problems were solved using hand analysis and validated through LTspice simulations.


## Chapter 3 — Single Stage Amplifiers

Documentation covering:

- Common Source Amplifiers
- Source Follower (Common Drain Stage)
- Common Gate Stage
- Cascode Amplifiers

Analysis includes:

- Circuit behaviour and operating regions
- Hand calculations
- LTspice schematics
- Simulation results and observations


## Chapter 4 — Differential Amplifiers

Documentation covering:

- Single-ended and differential operation
- Basic differential pair
- Qualitative and quantitative analysis
- Common-mode response
- Differential pairs with MOS loads
- Cross-coupled PMOS loads

Analysis includes:

- Hand calculations
- Cadence Virtuoso schematic design
- Cadence ADE-L DC simulations
- LTspice schematics and simulations
- Differential and common-mode behaviour
- Analysis of feedback and output resistance
- Comparison between theoretical predictions and simulation results
- Circuit behaviour, operating regions, and design observations

The simulations use the GPDK180 technology library with a 1.8 V supply voltage.


## Chapter 5 — Passive and Active Current Mirrors

Documentation covering:

- Basic Current Mirrors
- Cascode Current Mirrors
- Active Current Mirrors
- Large-Signal Analysis
- Small-Signal Analysis
- Common-Mode Properties

Analysis includes:

- Hand calculations
- Cadence Virtuoso schematic design
- DC and transient simulations
- Comparison between theoretical predictions and simulation results
- Circuit behaviour, operating regions, and design observations


## Tools Used

- Cadence Virtuoso (GPDK180)
- Cadence ADE-L
- LTspice
